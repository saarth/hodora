## Gallery — 1905 × 1140 (1270 × 760 at 1.5×)

`gallery/` holds composed launch images (Product Hunt's gallery size): a real
screenshot, a device frame and a line of copy. Build them with
`node scripts/screenshots/gallery.mjs` after a capture run.

## What's real in these

The UI is the app itself, running from source: the map is MapLibre drawing
`src/lib/cycling-style.ts`, the charts are the app's charts, and the
navigation screens are following a GPS feed through the same code a phone
runs. The account, the rides and the rider's position are supplied by the
harness, and so are the weather, POI, place-search and routing responses —
see `scripts/screenshots/README.md`.

**The basemap in the committed images is a generated stand-in**, not real
OpenStreetMap data: the machine these were captured on can't reach the tile
host, so the run fell back to procedurally generated countryside with
invented place names (Ashcombe, Cranmoor, Upper Dray…). Everything else is
the real app.

Before publishing these anywhere that implies real map data — a store
listing, Product Hunt, AlternativeTo — re-run `npm run screenshots` on a
machine with network access. The run uses the real tile provider whenever it
can reach it, and prints which basemap it used.
